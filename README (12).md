# Customer Lifetime Value (CLV) Analysis

## Project Overview

This project estimates **Customer Lifetime Value (CLV)** using
historical customer purchasing behavior from the **Online Retail II**
dataset.

The analysis uses Python for data cleaning and customer-level
calculations, and Excel for the final CLV table, customer segmentation,
and visualizations.

## Objectives

-   Clean and prepare retail transaction data.
-   Calculate customer-level purchasing metrics.
-   Estimate CLV using two approaches.
-   Compare historical and estimated CLV.
-   Segment customers into High Value, Medium Value, and Low Value
    groups.
-   Present the results in an Excel workbook.

## Dataset

**Dataset:** Online Retail II

The dataset contains retail transactions with information such as:

-   Invoice
-   Invoice Date
-   Customer ID
-   Quantity
-   Price
-   Product Description
-   Country

## Tools Used

-   Python
-   Pandas
-   Matplotlib
-   Excel

## Data Cleaning

The following steps were applied:

1.  Removed transactions with missing Customer IDs.
2.  Removed transactions with missing descriptions.
3.  Excluded cancelled invoices.
4.  Removed transactions with non-positive quantities.
5.  Removed transactions with non-positive prices.
6.  Calculated transaction sales using:

``` text
Sales = Quantity × Price
```

## Customer-Level Metrics

The following metrics were calculated for each customer:

-   Total Sales
-   Total Orders
-   Total Items
-   First Purchase Date
-   Last Purchase Date
-   Customer Lifespan
-   Average Order Value
-   Annual Purchase Frequency

## CLV Methods

### Method 1 --- Historical CLV

Historical CLV represents the total revenue generated by a customer:

``` text
Historical CLV = Total Customer Sales
```

### Method 2 --- Estimated CLV

Estimated CLV uses the customer's observed purchasing behavior:

``` text
Estimated CLV =
Average Order Value × Annual Purchase Frequency × Expected Lifespan
```

For this project, the expected future lifespan was assumed to be **1
year**.

## Customer Segmentation

Customers were segmented using their Estimated CLV.

The three segments are:

-   **High Value**
-   **Medium Value**
-   **Low Value**

The thresholds were based on the 25th and 75th percentiles of Estimated
CLV.

## Key Findings

-   The analysis identified **4,312 customers** across the three CLV
    segments.
-   The High Value segment has the highest average estimated CLV.
-   The Medium Value segment contains the largest number of customers.
-   The Low Value segment has the lowest average estimated CLV.
-   Historical CLV measures value already generated, while estimated CLV
    provides an estimate based on continued purchasing behavior.

## Assumptions

-   Historical purchasing behavior is used as the basis for estimating
    future value.
-   The estimated CLV assumes the observed purchasing frequency
    continues for one year.
-   Cancelled and invalid transactions are excluded.
-   Customers without a Customer ID are excluded from customer-level
    analysis.
-   The CLV estimates are analytical estimates and are not guaranteed
    future revenue.

## Limitations

This project uses a simplified CLV approach. It does not explicitly
model:

-   Customer churn probability
-   Profit margins
-   Customer acquisition cost
-   Discount rates
-   Individual product margins
-   Probabilistic future purchasing behavior

A more advanced CLV model could incorporate these factors using
retention models, probabilistic models, or machine learning.

## Conclusion

This project demonstrates how transaction-level retail data can be
transformed into customer-level CLV measures. Two CLV approaches were
calculated and compared, followed by customer segmentation based on
estimated value.

The analysis provides a practical example of using Python and Excel to
support customer value analysis and data-driven segmentation.
